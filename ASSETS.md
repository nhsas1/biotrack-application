# BioTrack assets

Scientific interface icons are locally bundled from `lucide-react` (ISC license). The selected microscope and DNA assets were inspected at https://lucide.dev/icons/microscope and https://lucide.dev/icons/dna. The application uses DNA, sample, flask, and supporting navigation icons in this consistent line-icon family.

Inter typography is locally bundled from `@fontsource/inter`. The original BioTrack brand mark is `public/logo.svg`. The researcher avatar uses fictional initials rather than a real person's photograph. No stock photography, patient images, or remote runtime assets are used.
