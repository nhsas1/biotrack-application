# BioTrack — project outcomes

## 1. Mobile-first application shell and navigation — Complete
- Build a simple, professional, mobile-first biotechnology laboratory management application called **BioTrack** for biomedical researchers and laboratory technicians to manage biological samples and track experiments.
- Use a modern, minimal healthcare/biotechnology design with a white background, teal and navy-blue accents, rounded cards, clean typography, and simple scientific icons.
- Use a mobile portrait layout with a fixed bottom navigation bar containing four tabs: Home, Samples, Experiments, Profile.
- Provide smooth transitions and responsive, touch-friendly buttons.
- All navigation tabs and buttons must work.
- Use simple local state or local storage for this first prototype.
- Do not integrate a real database, authentication, external APIs, or AI chatbot yet.
- Do not use or request actual patient information.
- Include a clear empty state where needed.

## 2. Home dashboard — Complete
- Show the welcome message: “Welcome back, Researcher!”
- Show summary cards: Total Samples (48), Active Experiments (6), Pending Tasks (4).
- Show a Recent activities section.
- Provide the quick-access button “Add New Sample”.

## 3. Samples and sample details — Complete
- Show a list of 8 fictional biological samples.
- Include the categories Blood, DNA, RNA, Tissue.
- Each sample has an ID, sample type, collection date, and status.
- Provide a search bar and category filters.
- Clicking a sample opens a details screen.
- Provide a functional “Add Sample” form that updates the displayed sample list.
- Make search, filters, and sample addition functional.
- Use realistic but entirely fictional demonstration data.

## 4. Experiments and experiment details — Complete
- Show a list of fictional experiments: PCR, DNA Extraction, RNA Sequencing, Cell Culture.
- Show status labels: Planned, In Progress, Completed.
- Show progress bars.
- Clicking an experiment shows its details.
- Use realistic but entirely fictional demonstration data.

## 5. Researcher profile and preferences — Complete
- Show a fictional researcher name and profile avatar.
- Show role: Biomedical Researcher.
- Show laboratory: BioTrack Research Lab.
- Provide basic editable preferences.
- Use realistic but entirely fictional demonstration data.
